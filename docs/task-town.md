# 任务公司

## 场景与状态

面板以第三人称公司场景为主体。沐沐是用户控制的角色；每个作业或网课任务对应一个员工。任务仍按账号及作业、课程去重，保留最新执行记录和既有详情、结果、删除权限。

| 区域 | 状态 | 员工表现 |
| --- | --- | --- |
| 公共办公区 | queued、running、stopping | 坐在带电脑和键盘的工位上工作 |
| 独立休息室 | completed | 躺在大沙发上休息，闭眼并缓慢呼吸 |
| 独立介入室 | needs_intervention、awaiting_user、incomplete、interrupted、failed、paused、stopped | 由天花板支架和绳索悬挂，保留各状态的独立颜色，轻微摆动 |
| Boss 工作室 | 总览及一个正在运行的浏览器 | 办公桌、座椅和实时大屏 |

办公区默认提供 12 个带电脑、键盘、鼠标、杯子和办公椅的工位。任务量增加时，工位、沙发坐垫和悬挂支架按需增加，房间纵深同步扩展。任务身份决定角色形状，重试保留形状；任务状态决定颜色、位置和姿态。

场景只展示后台状态。跨房间的移动和变色不会启动、提交、暂停或结束业务任务。右侧原有账号摘要收起，授权账号仍在“平台”页面管理。

## 操作

- 沐沐落地后可按空格跳跃，支持行走中起跳。空中再次按下、长按连发、文字输入和弹窗操作均不会触发额外跳跃，起落沿用场景重力与碰撞。
- 默认第三人称跟随沐沐。点击可通行地面后，沐沐自动绕开墙体和家具走到落点；再次点击更新目标。WASD 或方向键可随时接管，松开后不恢复旧路线。拖动调整镜头，滚轮缩放；拖动镜头不产生新的移动目标。
- 点击目标用地面圆环标记，到达后渐隐。不可达目标显示明确反馈；聚焦输入框、按 Esc、查看任务或切换房间会取消自动行走。点击 Bot、大屏及现有交互按钮仍沿用各自操作。
- 房间导航可直接前往办公区、休息区、介入区和 Boss 工作室。全景按钮切换到公司总览，手柄按钮返回跟随视角。
- 墙体、门口、桌子、沙发和办公台由 Cannon 处理碰撞。镜头旋转不会改变重力；室内镜头会避开实体墙，靠近房间时移除挡住视线的前侧隔断。
- 悬浮员工显示任务名称及账号。点击员工拉近镜头，并显示原有任务操作卡。查看任务、查看结果和删除权限沿用既有业务逻辑。
- 靠近同一房间的员工时，显示选中圆环和 F 提示。按 F 打开同一操作卡；不跨墙提供交互。
- 靠近 Boss 办公桌，按 F 入座并打开与点击沐沐相同的总状况。关闭总览后，按 F 起身，也可直接用移动键离座。
- 搜索框、账号筛选和弹窗内的输入不会移动沐沐。关闭任务卡会返回跟随视角并恢复画面焦点。
- 暂停场景动效仅控制视觉动画。业务任务继续执行；新的任务状态仍会同步到对应房间。减少动效设置会关闭呼吸、摆动及跨区行走，并直接切换镜头。

## 实时大屏

大屏只选择 status 为 running 且 browser_available 为 true 的任务。默认选中一个可用任务，用户也可从大屏任务选择器中切换。任务结束或浏览器不可用时，旧连接关闭，再选择其他可用任务；无可用任务时显示公司运行概况。

浏览器连接沿用现有 browser/session 和浏览器 WebSocket 接口。大屏独立申请查看票据，将连续帧绘制到 Three.js CanvasTexture。它只发送查看票据，不发送鼠标、键盘、执行、停止或关闭任务指令。点击大屏可打开对应任务的既有详情。

连接中、已断开和空闲均有明确展示。断开后可手动重新连接。切换任务、离开面板、重新加载场景或 WebGL 上下文丢失时，释放查看连接；这些动作不会停止任务或关闭后台浏览器。过时票据和旧连接帧通过代次检查丢弃。

## 实现与维护

| 文件 | 职责 |
| --- | --- |
| desktop/src/lib/task-company.js | 房间映射、稳定角色身份、容量布局、迁移路线及大屏任务选择 |
| desktop/src/lib/task-company-physics.js | 沐沐控制、固定重力、实体墙及家具碰撞 |
| desktop/src/lib/task-company-navigation.js | 基于现有碰撞障碍的 PathFinding.js A* 寻路、落点到达和取消控制 |
| desktop/src/lib/task-company-environment.js | 办公家具、独立房间、门口、灯具、植物及大屏 |
| desktop/src/lib/task-company-characters.js | 12 种单体角色、面部、悬挂绳索及沐沐水球 |
| desktop/src/lib/task-company-scene.js | 透视相机、跟随、镜头碰撞、动画、交互、纹理及资源释放 |
| desktop/src/lib/task-company-screen.js | 被动查看票据和流连接，隔离旧帧与任务操作 |
| desktop/src/components/TaskTown.vue | 搜索、筛选、房间入口、员工弹卡和总览事件 |
| desktop/src/task-town.css | PC 布局和场景界面 |

Three.js、Cannon 和场景代码按需加载。定向灯提供真实阴影，角色几何体及办公家具均在本地生成。页面隐藏时跳过场景绘制；离开面板时释放连接、事件、观察器、物理世界、材质、几何体、纹理及渲染器。布局容量变化后重建环境时，先释放原有环境资源。

## 验证范围

2026 年 11 月 13 日新增公司专项单元测试，覆盖状态分房、颜色区分、100 个同状态任务的布局容量、稳定身份、门口与家具碰撞、被动查看连接及旧连接隔离。

前端完整回归共 137 项通过，包含 6 项公司专项及 5 项点击寻路专项测试；生产构建通过。原有大体积 3D 分包的构建提示仍存在，场景保持按需加载。

浏览器验收使用隔离的任务响应和连续变化的浏览器测试帧，不创建或执行真实作业。检查项目包括第三人称移动、输入保护、靠近 F 交互、老板入座和起身、沙发角色详情、真实 Canvas 像素变化、状态迁移、60 个任务、页面退出，以及 1651、1343、1183 像素宽的 PC 布局。

大屏验收验证了现有票据和帧协议接入，查看端只发出测试查看票据，未发出业务操作。若当前没有可用的真实运行浏览器，显示空闲概况，不把测试帧当作真实任务画面。
