## 使用流程

1. 在“平台”选择“头歌”，点击“授权”。
2. 在软件新开的 Chrome 窗口完成登录，等待软件读取名称、头像并保存授权。
3. 进入该账号的“作业”，点击获取课堂，选择要处理的课堂并保存。
4. 点击“采集”，查看未完成且当前可提交的实验。
5. 点击“执行”。默认保存代码后等待人工审核；需要自动评测时，先显式开启并确认“允许自动评测”。
6. 在实时浏览器核对代码、文件和关卡状态。人工处理后可继续原任务；完成依据以平台回读为准。

常用 Chrome 的登录态不会自动复制到软件管理的 Profile，首次需要在独立窗口登录。重新授权现有账号会保留本地账号 ID 及已有任务关联。

## 请求与状态约束

头歌客户端先打开官方页面，观察该页面正常产生的当前会话请求头，再请求允许的头歌 API。不在代码中嵌入平台签名密钥，也不把一次捕获的签名永久复用。签名过期时刷新自己的任务页面；初始化或刷新失败返回明确错误。

“代码已保存”“当前关卡已通过”“全部关卡已通过”“课堂结果已核验”分别记录。评测已发出但结果未知时，禁止盲目重复提交；提交前的普通失败不会伪装成已经提交。

首版不支持云桌面、Jupyter、图形仿真、文件交付型实验或非 Java 文件。遇到不支持环境时保留具体原因和任务窗口，交由用户处理。
