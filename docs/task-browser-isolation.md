# 任务浏览器隔离

## 账号与任务

账号资料目录是授权来源，保存登录时导出的 Cookie 和 localStorage。执行任务不会直接使用或改写这个 Chrome 目录。

每个作业和网课任务创建独立临时目录。目录名包含任务类型和任务 ID，并带随机后缀。不同任务使用不同 Chrome 进程、CDP 控制连接和实时画面通道。任务关闭后清理自己的目录，待人工处理时保留到用户关闭窗口。

同一个作业或课程仍禁止重复启动。人工继续复用本任务窗口；重试关闭本任务旧窗口后创建新窗口。停止一个任务不会关闭其他任务的浏览器。

授权、账号删除和课程采集继续遵循各自的占用保护。作业和网课执行互不排斥，自动任务遵循系统配置的执行并发。

## 前台路由

作业页只显示所选账号的作业任务。选择任务后固定连接该任务，不再回退到该账号的网课浏览器。已有多个作业记录时，可通过“作业窗口”切换。

网课页面按课程运行 ID 连接实时浏览器。实时连接票据绑定任务；断开查看端只清理查看连接，不结束任务。

“查看”使用按作业 ID 分配的手动窗口；对应作业已有运行中窗口时，直接打开原窗口。

## 沐沐

沐沐在面板主区域显示形象和本轮进度，任务操作统一使用面板列表。其他页面显示右上角入口，可展开本轮任务与全部待处理项。

主屏和右上角复用同一个组件实例，通过 Teleport 移动。切换页面保留本轮进度和动效偏好，避免同时出现两份任务入口。

## 验证

自动测试覆盖同一账号的真实双 Chrome：加载相同授权、隔离 localStorage、两路直播独立输入、关闭作业后网课仍可操作。另有同账号双课程暂停与停止测试，以及前端任务选择回归。

任务诊断记录包含 browser.workspace 事件，提供任务类型、任务 ID 和目录标识，不写入 Cookie 或密钥。
