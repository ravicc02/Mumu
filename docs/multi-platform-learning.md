# 多平台网课接入

## 平台与代码来源

平台清单来自 OCS 5.4.0 的六个平台工程，固定提交为 1e93399a22b54fac80bb6bae131a4b208b5d8af9。原文件、MIT 许可证和源码摘要存放在 third_party/ocs/。所有运行依赖均随本项目提供，课程任务不连接 OCS 的服务。

| 平台 | 入口与页面覆盖 | 上游文件 |
| --- | --- | --- |
| 学习通 | 原有课程中心、传统与新版章节目录 | cx.ts |
| 知到智慧树 | 共享课、融合课、StudyPlus、智慧课程、学堂、学堂新版；含 polymas.com | zhs.ts |
| 中国大学 MOOC | 传统学习页与智慧慕课的单元、章节切换 | icourse.ts |
| 智慧职教 | MOOC 学院章节目录、学习中心链接目录 | icve.ts |
| 职教云 | 新职教云、资源库的 Vue 课程数据、任务入口 | zjy.ts |
| 雨课堂 | AI 课程任务目录、完成标记；平台域名包括 xuetangx.com 和 gdufemooc.cn | yuketang.ts |

平台注册表示该平台已有本地适配器，不等同于所有机构页面版本都已通过真实账号验收。尚未识别的目录会报出明确错误并保存诊断现场。

## 用户流程

1. 在“平台”选择对应平台，再添加账号。
2. 学校使用独立入口时，填写学校／平台入口；地址必须属于所选平台的 HTTPS 域名。
3. 在授权浏览器完成登录。自动识别未完成时，点击账号旁的“已完成登录”。确认操作会保存当前 Profile、Cookie 和站点存储。
4. 在“网课”选择账号，采集课程。学习通保留开课年份筛选；其余平台按当前账号页面读取课程，不伪装成支持年份筛选。
5. 自动采集未得到课程链接时，可以明确填写课程名称和学习链接，点击“加入课程”。这不会隐藏原有课程。
6. 点击执行。目录识别、跳过已完成任务、媒体播放、暂停、停止、重试、实时浏览器、通知和诊断均由本系统管理。

自动处理范围为视频、音频。阅读、练习、验证和未识别的任务进入待人工处理，保留同一个浏览器。不会随机填写练习、自动发表评论或通过伪造进度请求标记完成。

## 底层边界

- 平台目录、支持域名、Logo 和能力标记集中在 backend/app/services/platforms/catalog.json，前后端共用。
- 学习通保持原有适配器；新增平台通过 create_learning_browser 创建 OCSLearningBrowser，使用同一个 LearningService 状态机和账号锁。
- 课程身份包含账号、平台、课程与班级。新增平台的数据不会写成学习通，也不会与另一平台的课程混淆。
- 新增平台通过隔离的授权上下文重新读取平台页面核验目录，避免刷新正在播放的页面。验证页的课程标识必须与任务一致。播放器结束不能单独触发“已完成”。
- MOOC 跨章节切换复用上游导航算法。替代 RemotePlaywright 的本地动作桥仅允许本次请求中的课程导航点击，不提供任意脚本执行或任意请求代理。
- Cookie 和站点存储保存在账号本地数据目录。诊断包保留平台、引擎版本、运行源码摘要、目录与错误现场，凭证经过脱敏。
- 新增平台当前只开放网课入口。作业采集、答题和作业定时采集保持学习通能力，不会给新增平台显示未实现的作业入口。

## 复用构建与验证

原始 TypeScript 文件保存在 third_party/ocs/upstream/projects。构建脚本通过语法树提取原有章节处理器、完成判定和导航函数，生成 ocs-study.js。平台运行协议与宿主控制在独立文件中适配，不直接运行上游的自动续播、重置播放位置及自动讨论代码。

在项目根目录执行：

~~~powershell
node scripts/build-ocs-study.mjs
cd backend
python -m unittest discover -s test -p test_multi_platform.py -v
~~~

upstream-manifest.json 记录固定提交、六个原文件的 SHA-256、摘取位置和生成运行文件的摘要。修改上游代码后应重新构建并运行测试，不能只替换某个已生成文件。

现有测试覆盖六个平台清单、五个新增平台的目录标记、智慧树多种页面、域名边界、平台独立存储、授权存储恢复，以及本地智慧职教音频播放至平台复验的流程。新增平台仍需分别使用真实账号和课程验收机构定制、播放器拦截与平台版本差异。
