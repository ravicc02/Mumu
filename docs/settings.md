# 设置与自动执行

## 配置入口

设置页分为模型配置、作业配置、网课配置和系统设置，各类配置独立保存。作业、网课和系统表单在本地保留未保存的草稿。

模型表单提供供应商名称、接口地址、API Key、模型顺序和思考强度。密钥留空时保留原值，读取配置时不返回密钥。顶部模型入口复用同一表单。

## 自动检测与执行

每个支持作业采集的账号分别设置检测开关、间隔和自动完成开关。

- 间隔支持 s、min 和 h，范围为 5 秒至 7 天。后端每秒检查到期账号。
- 应用和本地后端需要持续运行，关闭后不执行检测。
- 定时检测采集当前学年的作业。账号未授权时等待重新授权。
- 同一账号的采集和浏览器操作互斥。不同账号可以并行检测。
- 系统设置控制检测并发，默认同时检测 2 个账号。

自动完成默认关闭。启用时，系统将已知作业记录为基线。对于没有已知作业和成功采集记录的账号，首次完整采集只建立基线。部分采集不会提前结束这一步。

后续定时采集发现新作业时，系统检查作业是否未完成且可提交。符合条件的作业进入持久化队列。重复采集、应用重启和通知开关变化均不会重复创建任务。已有执行记录的作业需要用户手动重试。

授权或采集尚未结束时，自动任务等待。不同作业和网课使用独立浏览器，不再互相等待账号锁。自动执行仍遵循已设置的并发上限。没有模型配置时保持等待，设置页显示数量和原因。

关闭自动完成会取消等待项，并停止自动创建且仍在排队的任务。运行中的任务继续执行，用户可在任务详情暂停或停止。手动任务不受这个开关影响。

## 执行默认值

| 配置 | 默认值 | 生效范围 |
| --- | --- | --- |
| 学习通最终提交 | 关闭 | 学习通新建手动任务和自动任务 |
| 头歌自动评测 | 开启 | 头歌新建任务、重试及人工处理后的继续 |
| Agent 最大步骤 | 100 | 新启动的浏览器 Agent |
| 自动执行并发 | 1 个任务 | 自动创建的任务 |

两项权限分别位于“设置 → 作业配置”。作业页提供配置入口，浏览器默认可操控。头歌自动评测独立于学习通最终提交，保存代码后直接评测。

最终提交关闭时，填写并暂存后进入待审核。保留的浏览器只占用当前任务资源，其他作业和网课可继续。用户审核后可独立关闭该浏览器。

最终提交开启时，任务仍需核验平台结果。只有确认已提交才显示已完成。未完成、中断和提交状态不明的任务不自动重跑。

头歌按关卡读取完整题目、代码模板和占位内容。模型返回完整文件，保留原框架、原注释及 Begin/End 标记，不新增解释性注释。代码保存并回读一致后开始评测。明确的编译错误、运行异常或测试失败会反馈给模型，修正后再次评测，通过后进入下一关。每关最多 4 次模型请求、4 次评测，允许 3 次修复。

人工处理后点击继续，系统接回同一实验实例和当前关卡，读取并保留当前编辑器代码。已有评测运行时先查询原结果；结果未知或平台服务故障时保留现场并说明原因。仅保存模式仍可通过关闭“头歌自动评测”启用。

## 网课与系统

网课默认使用无头浏览器后台运行，不弹出 Chrome 窗口。软件内的实时画面仍支持鼠标、键盘和滚动，可点击“实时操控”进入全屏。关闭实时查看端不会暂停任务。

“后台运行”开关只影响新任务。关闭开关后，新任务显示独立窗口；直接关闭该窗口会使任务中断，日志记录浏览器关闭原因。账号授权仍使用登录窗口。

播放参数包括倍速、音量、资源加载等待、平台完成确认等待和播放无进展判定。默认值依次为 1 倍速、静音、15 秒、25 秒和 60 秒。

参数传入本地播放器与执行器。修改配置不会恢复人工暂停的媒体，也不会跳过平台完成核验。

任务运行时，启动被打断或播放器意外暂停会自动尝试恢复，连续最多 3 次。必要时点击可见的播放按钮；静音配置会同时设置播放器静音属性。自动恢复保留当前播放位置，不刷新页面、不跳过资源。媒体连续正常播放并前进 10 秒后重置恢复次数。自动恢复仍失败或出现验证、练习时才等待人工介入；用户点击任务“暂停”后不会自动恢复。

系统配置控制自动检测并发、内部现场记录的保留时间和空间上限。现场记录默认保留 14 天，上限为 200 MiB。

“存储目录 → 今日日志”指向 logs/main.log。主日志按事件分块排版，集中记录当天的任务、操作和错误详情。跨日后追加到 oldmain.log，再创建当天文件；这两个文件遵循自然日归档规则，不受现场记录空间上限影响。

后端启动和新任务创建时执行诊断清理。运行中任务与保留浏览器的任务受到保护。清理范围为诊断记录，其他业务数据保持原有存储方式。数据和日志目录支持在桌面版打开，在网页预览中复制路径。

## 微信消息

连接器提供新作业提醒和任务结果两个开关。新作业提醒来自定时采集，任务结果覆盖作业和网课。

消息保留状态、账号、课程或作业名称及简短结果。内部标识、完整页面链接和异常堆栈留在后台诊断中。连接器预览使用实际发送的同一个格式化函数。

```text
待审核 · 我的账号
软件工程｜实验四
已填写，等待人工审核
```

## 本地接口

- `GET /api/preferences`：读取作业、网课与系统配置。
- `PATCH /api/preferences`：保存指定分类，可同时原子保存账号调度。
- `PATCH /api/accounts/{id}/collection-schedule`：兼容原有分钟格式，支持数值、单位和自动完成开关。
- `GET /api/accounts`：返回检测配置、等待数量及原因。

配置通过类型和范围校验后保存。任一账号配置无效时，整个保存操作回滚。自动任务在数据库事务内认领作业并创建任务，防止重复入队。
