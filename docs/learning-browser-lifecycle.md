# 网课浏览器生命周期

## 运行模式

网课默认开启后台运行，使用无头 Chrome。任务仍拥有独立账号授权副本、浏览器目录和 CDP 连接，实时画面可以在软件中操控。

设置中的后台运行开关影响新任务和重试。每条 learning_runs 记录保存 headless 字段，切换设置不会修改已有任务的运行模式。旧记录迁移为窗口模式，避免历史显示失真。

学习通章节入口使用原生点击。章节在新页面打开时，执行器接管该页面作为当前播放页和实时画面来源，不再继续检查旧目录页。

无头任务提供 view_browser 操作，在前端展开同一实时画面。查看端只是后台任务浏览器的画面与输入连接。关闭查看页面、退出全屏或断开这个连接，只退订画面，不调用任务暂停、停止或浏览器关闭。再次查看会连接同一个任务浏览器，保留原页面和播放进度。

窗口模式保留 open_browser 操作，可切到实际执行任务的 Chrome 窗口。这个原窗口承载任务本身，关闭它可能同时终止执行进程；它与无头模式的实时查看端不同。

## 状态判定

| 事件 | 状态 | 后续操作 |
| --- | --- | --- |
| 用户点击任务暂停 | paused，已暂停 | 用户继续或停止 |
| 播放器暂时停播 | running，运行中 | 最多自动恢复 3 次，保留播放位置 |
| 自动恢复失败、练习或验证阻塞 | awaiting_user，待介入 | 在软件内操控后继续 |
| 承载任务的浏览器进程退出或任务控制连接断开 | interrupted，中断 | 查看具体原因后重试 |
| 执行任务的页面关闭或崩溃 | interrupted，中断 | 查看具体原因后重试 |
| 用户点击任务停止 | stopped，已停止 | 可重新执行 |
| 关闭实时查看、切换页面或退出全屏 | 状态不变 | 任务继续运行 |
| 平台复验全部章节完成 | completed，已完成 | 查看结果 |

浏览器断开监听绑定执行任务的上下文和页面，不绑定实时查看端的 WebSocket。即使任务正在人工暂停或等待介入，执行浏览器失联也会结束等待并标记中断。正常停止、应用收尾和浏览器清理不会被误判为意外断开。

## 维护记录

诊断记录 browser.connection_lost 事件，包括断开原因和运行模式。任务日志先记录 browser_closed，再记录 interrupted。窗口关闭不再使用“本地服务退出”或“人工暂停”作为原因。

自动测试覆盖真实有头与无头 Chrome 的关闭事件，以及任务运行、人工暂停和待介入三个阶段的断开。查看端回归测试包含双端同步、关闭其中一端、关闭全部查看端、后台继续运行和重新查看同一执行页面，最后再关闭执行上下文确认中断信号。前端测试确认关闭无头查看组件仅关闭画面连接，不发送暂停或停止指令。
